Informations radio, égaliseur et 432 Hz

Les radios sont diffusées par des serveurs externes et nécessitent Internet. Certains flux peuvent ne pas fonctionner. Sur Android, l'égaliseur des radios utilise un effet audio natif lorsque la sortie le permet ; vérifiez son état dans le diagnostic. Le mode 432 Hz abaisse la hauteur sonore selon le rapport 432/440 en conservant le tempo : ce n'est pas une mesure de l'accordage réel du diffuseur. Dans un navigateur classique, l'égalisation peut nécessiter une autorisation CORS et le 432 Hz radio n'est pas garanti.

Les préréglages et corrections rapides ajustent les huit bandes de l'égaliseur, y compris sur Media3 si l'effet Android est disponible. Sur une radio native, les réglages rapides activent automatiquement « Égaliseur Hi-Fi natif pour les radios ». Le 432 Hz reste un réglage indépendant, sauf le profil Fidélité FLAC qui sélectionne Original. Aucun profil ne garantit une sortie bit-perfect.

Pour les fichiers locaux dans l'ancien lecteur Web Audio, le 432 Hz ralentit la lecture au ratio 432/440 (−1,82 %) et baisse toutes les hauteurs musicales. Avec Media3, le réglage 432 Hz applique une conversion de hauteur sans changement intentionnel de tempo, lorsque disponible, y compris pour les radios natives. Il ne garantit pas qu’un enregistrement ait été accordé en 440 Hz à l’origine. L’écran éteint, la lecture dépend d’Android et du navigateur.
